# 水のあいだ — Liquid study / 01

独立したWeb屈折試作です。指先に透明なレンズを重ね、動いた跡を約0.8秒で消します。

「カメラではじめる」を押して、明るい場所で片手を開く・曲げる・左右に動かしてください。映像は端末内処理。停止やページ離脱でカメラを解放します。

「カメラなしで質感を試す」はポインター／自動デモで、実手追跡とは別です。森の背景はこの試作用にコードで描いたものです。

手追跡はApache-2.0のMediaPipe Hands 0.4.1675469240の軽量モデルを同梱。カメラ映像のアップロード、外部API、広告・解析サービスは使用していません。必要なプログラムとモデルはこのパスから取得します。ライセンスはvendor/hands/LICENSEを参照。

2Dの画面空間で屈折を近似しています。LiDARやARKitと同じ空間精度を保証しません。

iPhone Safari実機は未検証です。明るさ、指の重なり、速い動き、発熱・連続使用について実機での調整が必要です。
