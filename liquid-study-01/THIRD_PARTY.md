# Third-party component

`vendor/hands` contains unmodified runtime files from the npm package `@mediapipe/hands`, version `0.4.1675469240`, plus a copy of the Apache license. The unused full model, TypeScript declarations and npm packaging metadata are omitted.

Source archive: https://registry.npmjs.org/@mediapipe/hands/-/hands-0.4.1675469240.tgz
Upstream: https://github.com/google/mediapipe
License declared by the package: Apache-2.0. Full text: `vendor/hands/LICENSE`.
Copyright notices embedded in upstream files are retained. The archive did not include a separate NOTICE file.

`app.js`, `renderer.js`, UI, generated forest and the demo movie are new work for this prototype. Liquid Handz source, branding, application assets and the user's reference videos are not included in the distributable ZIP. The project is an independent study, not an official Liquid Handz version.
